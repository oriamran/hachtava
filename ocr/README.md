# שרת קריאת דף ההכתבה

שרת קטן שקורא צילום של דף הכתבה ומחזיר את המילים עם ניקוד.

המשחק עצמו הוא קובץ HTML ואין בו מודל שיודע לקרוא תמונה. השרת הזה קיים כדי להחזיק את מפתח ה־API במקום שאיש לא רואה: אילו המפתח היה יושב בתוך הקובץ, כל מי שפותח אותו היה יכול לקחת אותו.

הוא לא שומר דבר. התמונה מגיעה, נקראת, והתשובה חוזרת.

## הפעלה

```bash
cd ocr
npm install
npx wrangler login
npx wrangler kv namespace create RATE
```

הפקודה האחרונה מחזירה מזהה. העתק אותו אל `wrangler.toml`, במקום `PASTE_KV_ID_HERE`. הוא משמש למגבלת הקצב.

הכנס את מפתח ה־API, והעלה:

```bash
npx wrangler secret put ANTHROPIC_API_KEY
npx wrangler deploy
```

בסוף הפריסה מודפסת הכתובת. הכנס אותה במשחק, במסך ההורים, בשדה "כתובת שרת הקריאה". בלי כתובת הכפתור לא מוצג והמשחק עובד אופליין במלואו.

## הגנות

הכתובת ציבורית, ולכן יש בה שתי מגבלות. `ALLOWED_ORIGINS` ב־`wrangler.toml` קובע אילו אתרים רשאים לפנות אליה, ומגבלת קצב מאפשרת עשרים קריאות לשעה מכל כתובת IP. בלעדיהן מישהו יכול להריץ אלפי תמונות על חשבונך.

## עלות

תמונה אחת עולה סנט או שניים. Cloudflare Workers חינמי עד מאה אלף קריאות ביום, וה־KV חינמי בהיקפים האלה.
